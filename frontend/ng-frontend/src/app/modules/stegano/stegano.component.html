Introduction

Using Eel and Python, we successfully developed a desktop application capable of performing steganography using a cover file and a payload. We supported .docx, image, .mp3, and .mp4 files as cover formats, and plain text, .docx, image, .mp3, and .mp4 as payload formats.

I was responsible for implementing .docx steganography support for all payload types. I was also tasked with integrating the application's frontend with the core logic and media display functionality.
