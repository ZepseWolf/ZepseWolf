Introduction

Using Express, MongoDB, Socket.IO, Flutter, Apache 2, and NGINX, we successfully developed a full-stack application designed to assist first responders in identifying potential threats.

I was placed in charge of the entire backend, while my teammates worked on the frontend. Unfortunately, we encountered significant frontend issues, resulting in an unstable application. However, all server endpoints are currently running and accessible via the Vercel link.

I also conducted an analysis to determine the optimal reverse proxy solution for the customer, evaluating load balancing performance and successful HTTP request frequency as key metrics.

*Please note that the server is hosted on Vercel's free tier, so Socket.IO, NGINX, and Apache 2 functionality will not be available. As this application was developed for GRAYMATICS SG PTE. LTD., many details have been omitted. Interaction is limited to HTTP requests, with CORS configured to allow public access.
