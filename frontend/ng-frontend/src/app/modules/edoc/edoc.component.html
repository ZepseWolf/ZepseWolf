Introduction

Using Angular 13 and Flask, we successfully developed a fully interactive application that tests students on their ability to read and interpret medical e-documents.

I was primarily responsible for developing the student-facing frontend and assisted with the admin interface. I was also tasked with managing the frontend development team, as I had the most experience with the framework.

This project required close collaboration with the client through weekly sprint-style meetings, during which we managed customer expectations and presented completed work.
