Introduction

Using Kotlin and Firebase, we successfully developed an Android mobile application designed to assist researchers in managing scope inventory — including viewing, handling, and scheduling — with ease.

I was primarily responsible for the scheduling section, where users interact with the calendar module to add and remove schedules.
