Introduction

Using HTML, JavaScript, and CSS, I successfully developed a responsive website where administrators can log in, log out, view the dashboard, view graphs, add new facts, and respond to student questions.

Students take a picture of a displayed fact and receive points when the admin approves it. Admins can also respond to student questions. This application is ideal for new students, giving them an opportunity to explore the school in an open-house-style setting.

*Please note that this application has no backend or serverless functionality, so no data is saved after the session ends.
