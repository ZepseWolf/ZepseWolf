Introduction

Using Watson APIs, Mongoose, Node.js, and Heroku, we successfully implemented and launched a live server with a complete REST API that performed database operations and a matching algorithm.

I developed the entire backend of the application. This project aimed to connect employers and employees, similar to LinkedIn but with a more targeted approach. We used IBM Watson's Text to Cognitive analysis to determine the most suitable employee match.

Unfortunately, the application was not adopted as an official company product, as it was developed under a tight deadline and the execution fell short of expectations.
