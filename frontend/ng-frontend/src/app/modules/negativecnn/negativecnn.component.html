Introduction

Using UiPath, Python, and TensorFlow, I successfully developed a script capable of mining data and classifying whether a Twitter user's sentiment is negative or positive.

The model was trained on data scraped from positive news articles and negative internet comments. This application demonstrates that with proper data scraping and AI, it is possible to achieve strong sentiment classification capabilities even without a dedicated NLP model.
