Introduction

Using Arduino only, we successfully developed a functional LoRa outdoor location tracker using triangulation and a self-healing BLE mesh network with the M5StickC Plus.

I was primarily responsible for delivering the self-healing BLE mesh component and contributed to the LoRa setup. The project aimed to compare communication methods between these IoT components to identify their potential real-world applications.

*Please note that as my primary contribution was the self-healing BLE mesh, only that component is demonstrated.
